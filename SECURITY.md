# Security Policy

## Supported Versions

Currently I only provide security updates for the latest version of Ry2.


| Version | Supported          |
| ------- | ------------------ |
| > 2.1.x   | / Yes             |
| < 2.1   | X No              |

## Reporting a Vulnerability

If you discover a security vulnerability within Ry2, please do NOT report it through public GitHub issues. Instead, please report it privately to help us protect our users.

### How to Report
Please send an email to **[johnryzon2@gmail.com]** with the following details:
- **Type of Issue**: (like Buffer overflow, memory leak in the VM and others)
- **Reproduction Steps**: A small `.ry` script that triggers the issue.
- **Impact**: What could an attacker do with this vulnerability?

### Our Response Process
1. **Initial Response**: I usually acknowledge your report in the weekends.
2. **Validation**: I will work to verify the issue within 10 business days.
3. **Fix and Disclosure**: Once a fix is ready, we will release a new version and publicly credit you for the discovery.

Thank you for helping keep Ry2 and its users safe!
